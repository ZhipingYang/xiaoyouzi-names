# 小柚子的取名册

杨姓女宝，小名小柚子。家人希望名字有水意、读起来好听且适合长期使用；母姓叶可以作为纪念，但不必强行放进每一个名字。

**[打开在线取名册](https://zhipingyang.github.io/xiaoyouzi-names/)**，默认从史传经世开始。2026年11月这次重审逐个检查了旧库，撤下大量生硬拼字和典源联系牵强的候选；数量明显减少，便于真正比较；偏现代日常，保留少量有文脉的名字。

## 如何看待出处

《岳阳楼记》“汀兰”、《老子》“若水”等可回到原典；“清婉”是从“清扬婉兮”隔字取意。其他许多名字属于现代字义组合，没有足够紧密的出处就明确写“自由新拟”。原典可作为欣赏背景，名字是否自然、好写、顺口更重要。

使用现代简体笔画：通常单字不超过13画，全名不超过30画。**伊露**按此前指定保留，是34画的例外；《蒹葭》也有追寻未得的情绪。普通话声调与规范字可以程序核对；莆仙、闽南方言还需家人按本地口音连读，听感与审美最终由家人决定。

## 本地生成和检查

`data/names.json`保存六篇现行正文，`data/listening-top20.json`保存好听篇（文件名沿用，实际数量以内容为准）；榜单与字库引用这两份数据。修改后运行：

```sh
python3 scripts/render_catalogue.py
python3 scripts/audit_names.py
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000`。Pages从仓库master根目录部署；历史纪事与草稿数据留作溯源。
