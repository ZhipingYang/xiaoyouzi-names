# 小柚子的取名册：416名重选版

女宝，杨姓；母姓叶。小名已经定为**小柚子**。取名沿用家人“以水润双木”的文化偏好，以三字姓名的读音、字义、书写和终身使用感为实际筛选依据。公开仓库不记录家人生辰等隐私。

## 本轮质量规则

每名附拼音、三字声调、现代简体笔画账、可回查原典、取法、意蕴和评级。七篇各自含“清”≤2个、同首字≤2个、极品≥40%；三连同调禁入，完整姓名全库零重复。极品是项目审美评级，不是客观鉴定。

单字≤13画，澜15画仅豁免单字上限，全名仍≤30画。**伊露是显式例外：杨7＋伊6＋露21＝34画**，并保留《蒹葭》追寻未得的语境说明。旧榜的清嘉32画、微澜35画均退出推荐。保留火种14名，其余402名为本轮新拟；旧版字库中的裸名示例也纳入旧库对照。

五关为听感／水德／真典正面／红线／终身。原句直取与依典义新拟明确分开，不把新拟组合写成古人原话。普通话和终身语用已经编辑筛；**莆仙、闽南方言仍待家人实读终验**。

## 站点与更新

`index.html`为静态阅读器，支持分组导航、直达胶囊、篇内目录、手机章节抽屉、表格卡片及明暗主题。原有README和专题深链仍可打开。纪事档案保留供溯源，不属于本轮推荐库。

本地预览：`python3 -m http.server 8000`，打开 `http://localhost:8000`。

日常修改以 `data/names.json` 与 `data/sources.json` 为准，再执行：

```sh
python3 scripts/render_catalogue.py
python3 scripts/audit_names.py
```

检查通过后提交并推送master；GitHub Pages从仓库根目录部署，无需构建工具。原典在线核对快照见 `data/source-verification.json`，离线硬项校验无需安装第三方库。
