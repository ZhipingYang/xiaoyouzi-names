## 取名方法

| 方法 | 示例 | 说明 |
| :--- | :--- | :--- |
| **截篇** | 湛露 ← 《诗经·小雅·湛露》篇题直取 | 从典籍成熟语句中保留最适合姓名的精粹部分 |
| **转意** | 伊露 ← 所谓伊人，在水一方＋蒹葭白露 | 融合双重水意象，并谐音“一路”寓顺遂 |
| **倒置** | 清婉 ← 婉如清扬 | 调整原句语序，使名字更加灵动自然 |
| **合典** | 江月 ← 春江潮水连海平＋海上明月 | 从同一首诗作中提取两个相隔的意象 |
| **藏意** | 河清 ← 俟河之清，人寿几何 | 化用典故翻出新意：海晏河清，盛世清象 |

## 核心筛选红线

1. **五行补水为纲（第一权重·生辰定音）**：女宝五行缺水，补水不止字形带水——① 水部字直取（汀、滢、沁、澜、溪、泉、清、澄）；② 水意象入名（江、月、雨、霁、露）；③ 水生木润泽杨叶双木；④ 调候降燥（火土偏旺尤需水润）。凡非水候选一律不入册；补水拒绝网红水字（泽、汐、霖、涵、浩、沫、沐），绝不以烂大街为代价。**女款水审美**：女名用“泉溪涟漪露雨澄清”之水（小、清、静、柔），忌“江海潮涛奔流”之水（大、壮、刚）——沧海、千帆、观海、百川、济世、浚哲等男名水已全部下架。
2. **彻底清理口语词**：严禁使用日常口语形容词、副词与口头动词（如“从容”、“舒怀”等），追求“名以表德”的深层隐喻。
3. **严防天气播报感**：十月只作意境暗线（如月涵、清嘉、素秋、澄江），严禁使用“初晴、天朗、秋晴”等直白词。
4. **避开网红字扎堆**：坚决不用梓、宸、轩、泽、睿、浩、宇、辰、奕、诺、汐等泛滥字。
5. **双姓融合统一采用“杨X叶”及谐音**：双姓融合一律杜绝“杨叶X”倒置语法（杜绝“杨树的叶子”口语前置感），严格统一为“杨X叶”正向结构，或以“烨/晔/樾/悦/玥”谐音化入，中字承转，尾字脆爽收音。
6. **严防名人光环压制**：杜绝像“林徽因（徽音）、黄执中（执中）、张居正（居正）、白居易（居易）”等名人替身名字。
7. **多方言发音安全**：严格排查普通话、莆仙方言及闽南方言（白读）中的不良谐音（如羊圈、羊汤、野猪、野心等）。
8. **全生命周期耐用**：名字必须经得起童年、学术求学、成年职场及正式公文场景的检验，庄重大气。
